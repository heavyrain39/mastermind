# Mastermind Boilerplate

Initial scaffold for the v0.1 desktop-first local web app.

## Scope of this scaffold

- React + TypeScript + Vite base
- Feature-oriented folder layout
- Placeholder screens for:
  - Batch queue
  - A/B player
  - Mastering controls
- Theme mode state (`light`, `dark`, `system`) skeleton

## Next steps

1. Install dependencies and run the app.
2. Connect queue state and real file workflow.
3. Port DSP pipeline from existing `web/` modules.
4. Add launcher strategy for double-click local browser start on Windows.
