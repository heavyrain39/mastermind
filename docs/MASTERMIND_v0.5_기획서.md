# 마스터마인드 (Mastermind) v0.5 기획/현황서

## 1. 문서 목적
- 본 문서는 `마스터마인드`의 기획 목표, 구현 상세 내역 및 현재 개발 현황을 한눈에 파악할 수 있도록 작성된 기준 문서다.
- 이전 문서를 덮어쓰지 않고 각 버전을 보존함으로써 기획의 발전 과정을 추적하고, 새로운 작업자(LLM/개발자 등)가 투입되었을 때 개발 콘텍스트를 명확히 인계하는 역할을 한다.

---

## 2. 버전 히스토리
- **`v0.1`**: 제품 컨셉/사운드 방향 정의 및 배치 마스터링 범위 설정
- **`v0.2`**: React/TS/Vite 기반 3패널 UI 골격 구축, Queue/A-B 연동 1차 구현(상태 시뮬레이터)
- **`v0.3`**: 실제 DSP 워커 연동, 모노/에러 처리 보강 등 내부 프로세싱 기반 마련
- **`v0.4`**: UX 최적화(좌/중/우 정보 밀도 재편), Canvas 기반 웨이브폼 실 렌더 / 즉시 재생 기능 구현, 드롭다운 프리셋 및 결과 일괄 다운로드(ZIP) 도입
- **`v0.5` (2026-02-21)**:
  - 전면적 UI/UX 고도화 (에디토리얼 + 카세트퓨처리즘 컨셉 통합)
  - 폰트 내재화(Inter, JetBrains Mono) 및 다크/라이트모드(Off-White & Deep Charcoal) 컬러 시스템 확립
  - 주요 주요 액션 버튼(Upload, Start, Download) 강조 및 상태 토글 디자인
  - 마스터링 파라미터 툴팁 텍스트의 직관적/사용자 친화적 개선
  - 3D 오디오 비주얼라이저(프레캉스) 모노톤 고정 테마 독립 패널 통합
  - 버튼/슬라이더 마이크로 인터랙션 및 레이아웃 안정성(CSS Grid auto-fit, min-height: 0 풀다운 대응 등) 극대화

## 3. 핵심 제품 철학 및 목표 (유지)
### "The Clever Audio Mastering Ally"
> JRPG/판타지 계열의 Instrumental WAV 플레이리스트를 YouTube 등 주요 플랫폼 환경에 맞춰, 일관된 볼륨(Loudness)과 맑은 톤(Warm & Clean Tone)으로 일괄 마스터링 해주는 순수 로컬 기반의 웹 앱이다.

- **대상/규모**: 한 번에 약 18곡 ~ 최대 50곡 배치 처리 (개인 작곡가/디자이너 타겟)
- **UX 철학**: 복잡한 플러그인을 숨기고 세련된 정밀 장비(카세트퓨처리즘)를 조작하듯 빠르고 직관적으로 전 곡을 A/B 비교 및 처리

## 4. 이번 작업 상세 (v0.5: 추가 디자인 고도화, 2026-02-21)

이번 버전에서는 사용자의 구체적인 디테일 피드백에 따라 기존의 v0.4 UI/UX를 극대화했습니다.

### A. 디자인 시스템 및 컴포넌트 완성 (`미니멀, 카세트퓨처리즘, 와이어프레임`)
- **타이포그래피**: `MuseoModerno`(로고), `Inter`(본문), `JetBrains Mono`(숫자/파라미터) 폰트를 100% 로컬 로드하여 속도와 감성을 충족.
- **색상 체계**: Light(`--bg: #f5f6f7`), Dark(`--bg: #101113`) 모드의 완벽한 전환 보장. 큰 그림자(`box-shadow`)와 그라데이션을 극도로 절제하고 와이어프레임 선(1px) 느낌을 강조.
- **버튼 및 호버**: `UPLOAD`, `START`, `DOWNLOAD ALL` 등 주요 핵심 버튼에 뚜렷한 테두리를 두르고, 호버 시 완벽한 색상 반전 애니메이션 적용.
- **툴팁 라이팅**: 너무 기계적인 용어로 구성되었던 마스터링 호버 툴팁(uiTips.ts) 설명문을 일반 작곡가/디자이너가 이해하기 쉬운 친절함과 건조한 안내자 톤으로 완벽하게 재정의.

### B. 3D 비주얼라이저 통합 및 배경 (`VisualizerCard.tsx`)
- 우측 마스터링 컨트롤 패널 상단에, 별개 프로젝트였던 3D 파티클 비주얼라이저(프레캉스)를 **완전히 독립된 스크린 패널**로 분리하여 통합.
- 앱 전체의 다크/라이트 모드와 무관하게 이 모니터 블록 만큼은 항상 완전한 암흑속(#050505)에서 밝게 빛나도록 **어드밴스드 화이트 모노톤 테마로 고정**.
- 입자 크기를 50% 줄이고 카메라 뷰(가상 베이스)를 20% 넓혀 시원하고 광활한 느낌을 부여.
- 인터랙션: 오디오 재생 시 파형에 맞춰 맥동하며, 일시정지 상태(Idle)일 때에도 베이스 파동 강도와 회전 속도를 높여 긴장감 있게 돌아가도록 최적화.
- 전체 앱 배경의 그리드 라인 흐름 속도를 주파수 상승에 맞게 4배 빠르게(7.5s 주기) 상향.

### C. 레이아웃 대응성 및 정리 (유연한 축소 및 확장)
- 앱 창의 세로 높이가 줄어들더라도 스크롤바가 생기지 않고, 중앙 웨이브폼과 우측 컨트롤 패널이 내용물에 맞춰 유연하게 쪼그라드는 `min-height: 0` Flex 레이아웃 적용. 
- 마스터링 영역이 압축되며 남는 상단 여백(`flex: 1`)을 **비주얼라이저 컴포넌트가 모두 흡수하여 최대한의 공간과 개방감을 확보**하도록 우측 레이아웃(right-column) 전면 개편.
- 패널 제목(Track Queue 등) 주변 장식선의 여백 부족 문제를 해결하여 시각적 안정감 도모.
- 중앙 패널 최하단의 `Download All` 버튼은 Footer에 완벽히 고정되어 언제나 즉각 접근 가능하도록 보장.

## 5. 현재 사용자 시나리오 (v0.5 기준 통합)
1. **로드**: 앱 진입 후 `Upload` 또는 드래그 앤 드롭으로 다수의 WAV 파일 업로드
2. **배치**: `QueuePanel`에서 대상 트랙만 체크 박스 선택 후 `START` 클릭
3. **상태 모니터링**: 큐의 프로그래스 바가 전진. 완료 시(`done`) 트랙 행 우측에 개별 다운로드 아이콘 생성
4. **결과 검증**: 중앙 `A/B Monitor` 패널에서 원본/마스터 각각의 `Play` 버튼이나 웨이브폼 캔버스 상의 드래그 클릭을 통해 즉각적인 변화 비교 (자동 Play/Pause 교차 스위칭 포함)
5. **사운드 튜닝**: 우측 `Mastering Controls` 패널에서 드롭다운 프리셋 지정 또는 LUFS Range 슬라이더 세밀 조작 (조작감 강화된 CSS 슬라이더 Thumb 피드백 동반)
6. **최종 산출**: 개별 다운로드 또는 중앙 패널의 묶음 `DOWNLOAD ALL(ZIP)` 실행

## 6. 발견된 이슈 및 개발 환경 리스크
- **Node 버전에 따른 Vite Build Crash**: v0.2에서 보고된 Node 24 환경의 Vite build transform 에러 현상은 본 단계까지도 남아있음 (기능 구현을 위한 개발서버 `npm run dev` 구동은 아무 문제가 없음). 실 서비스 배포 전 Node 20 LTS 컨테이너 등에서 `build + preview` 과정 재확인이 필수적임.

## 7. 향후 과제 (Next Steps for v0.6)

v0.5의 디자인, 레이아웃, 시각적 컴포넌트(비주얼라이저 포함) 최적화 및 툴팁 대응이 완벽하게 정리되었으므로, 다가오는 마일스톤(v0.6) 최우선 과제는 다음과 같습니다.

### 1. 실제 Web Audio DSP 및 메타(LUFS/TP) 렌더링 접합 로직 점검
- v0.3에 연동된 DSP 워커와 v0.5의 고도화된 UI 상태를 최종적으로 하나로 묶어(`processing` 딜레이 및 상태 관리), 처리 결과물 렌더링 및 ZIP 압축과정이 프로덕션 레벨에서 견고하게 동작하는지 종합 테스트하는 단계 필요.

### 2. Node 버전에 따른 Vite Build 에러 원인 추적
- 현재 `tsc -b` 빌드는 문제없이 통과하나 Vite build 과정에서 발생하는 Node 호환성 문제의 근본 원인을 파악하여 실 서비스 CI/CD 배포 파이프라인의 안전성을 보장할 것.

## 8. v0.5 완료 시점 기준체
- **에디토리얼 + 카세트퓨처리즘 통합 기조**가 CSS 및 컴포넌트 전체에 무결점으로 이식되었다.
- **웨이브폼 및 우측 패널의 Flexible Height** 처리 방식(`min-height: 0`, `flex: 1` 연계)으로, 브라우저 화면 높이 축소에도 컨텐츠 침범 없이 완벽히 대응한다.
- **입자가 세밀하게 축소된 독립 패널형 3D 비주얼라이저**가 어두운 모노톤으로 통합되어 시각적 역동성이 극대화되었다.
- **단일 Action Button(UPLOAD, START, DOWNLOAD ALL)** 의 확실한 클릭/호버 뎁스 확보 및 버튼 위치 직관화가 달성되었다.
- **마스터링 파라미터별 직관적이고 친절한 한국어 안내 툴팁**이 완비되어 일반 사용자들의 작업 접근성을 비약적으로 높였다.
